# Data Engineering Zoomcamp UI

这是一个基于 Streamlit 的数据工程课程 UI 项目，用于展示 Data Engineering Zoomcamp 课程的内容。

## 项目介绍

该项目是 DataTalksClub 的 Data Engineering Zoomcamp 课程的用户界面，提供了课程内容的导航和展示功能，包括 2024 年和 2023 年的课程内容。

## 技术栈

- Python
- Streamlit
- st_pages

## 如何运行

1. 克隆仓库
   ```bash
   git clone https://github.com/weimasun/test.git
   cd test
   ```

2. 安装依赖
   ```bash
   pip install -r requirements.txt
   ```

3. 运行应用
   ```bash
   streamlit run app.py
   ```

## 项目结构

- `app.py` - 主应用文件，包含页面配置和主要内容
- `requirements.txt` - 依赖包列表
- `dezoomcamp/` - 课程内容目录

## 功能说明

- 课程内容导航：提供 2024 年和 2023 年课程的模块和章节导航
- 课程信息展示：显示课程概述、先决条件、讲师信息等
- 注册和联系信息：提供课程注册链接和联系方式
